# JPY → BDT 為替レート予測

実際の日次JPY→BDT為替レートをダウンロードし、モデル化し、インタラクティブなHTMLダッシュボードで結果を可視化する、セルフコンテインドな機械学習プロジェクトです。

![JPY→BDT 予測ダッシュボード](assets/crop_hero.png)

時系列予測の学習演習として、また「データの理解がニューラルネットワークの追加より勝る理由」のレッスンとして構築されました。


## モデルアーキテクチャと進化

このプロジェクトは、JPY→BDT為替レートの予測のために**複数のモデリングアプローチ**を探索し、複雑なニューラルネットワークを使用するだけでなく、基盤となる通貨市場のメカニズムの理解に重点を置いています。

### **重要な洞察：通貨ペアの分解**
プロジェクトは通貨市場に関する重要な観察から始まります：
```
JPY/BDT = (BDT per USD) / (JPY per USD)
r(JPY/BDT) = r(USD/BDT) − r(USD/JPY)
```

**これが重要な理由：**
- **USD/JPY（円レッグ）：** 自由変動の市場レート（ランダムウォークの動作）
- **USD/BDT（タカレッグ）：** バングラデシュ銀行による管理レート（強い平均回帰を示す）

### **モデルのバージョン**

#### **v1: 単純LSTM（ベースライン）**
- **アーキテクチャ：** 2層LSTM（64/32ユニット）+ ドロップアウト（0.2）
- **特徴：** 日次対数リターン
- **パフォーマンス：** 約60%の方向性精度（不安定 - ランダムシードによって40-60%の範囲で変動）
- **限界：** 通貨市場の構造を理解していない

#### **v2: 強化LSTM**
- **改善：** USDクロスレートレッグを特徴として追加
- **特徴：** [return, |return|, USD/BDT, USD/JPY]
- **パフォーマンス：** 約60%の方向性精度（依然として不安定）
- **限界：** 構造的洞察のない複雑なモデル

#### **v3: 構造的AR(1)モデル**
- **画期的進歩：** 通貨分解に焦点
- **アプローチ：** USD/BDTの平均回帰を予測、USD/JPYはランダムウォークとして扱う
- **特徴：** USD/BDTのラグ付きリターン
- **パフォーマンス：** 62.0%の方向性精度（分割間で安定）
- **重要な発見：** USD/BDTはラグ1自己相関が-0.26（強い平均回帰）

#### **v4: 曜日条件付きリッジ回帰（最終モデル）**
- **アーキテクチャ：** 曜日依存の特徴を持つリッジ回帰
- **特徴：**
  - USD/BDTのラグ付きリターン（1-3日）
  - 10/20日移動平均からの偏差（レベル回帰）
  - USD/JPYのラグ付きリターン（ランダムウォークのベースライン）
  - 曜日ダミー（月曜日から金曜日の指標）
  - 相互作用項：USD/BDTラグ × 曜日（曜日効果を捉える）
- **主要なイノベーション：**
  - 月曜日効果：β ≈ -0.98（週末の調整がほぼ完全に反転）
  - 中週効果：β ≈ -0.13（弱い平均回帰）
- **パフォーマンス：** **69.3%の方向性精度**（すべての分割で安定）
- **高信頼モード：** 最も強い25%の信号のみを呼び出すと80.0%の精度

### **モデル評価プロトコル**
- **80/20時系列分割：** 728日間の訓練、182日間のテスト
- **ウォークフォワードバリデーション：** モデルは毎日利用可能なデータで再調整
- **訓練のみの校正：** すべてのハイパーパラメータはテストデータに触れずに選択
- **データリークなし：** 訓練、検証、テストセットの厳格な分離

## 高信頼（選択的）モード — 約80%への誠実なルート

毎日のFX方向を予測するのは難しいです（ここでは約69%）。しかし、モデルは**信号の弱い日に「予測なし」と言うことができ**、信号が強い場合にのみ予測します。信頼しきい値は**テストセットなしで校正**され（訓練ウィンドウ内のブロックウォークフォワード適合；しきい値 = 予測の|prediction|のパーセンタイル）、凍結されてテスト日に適用されます。ダッシュボードの予測行には、15%カバレッジしきい値を使用した`high_confidence`フラグが含まれています。

## 結果（サンプル外、182日のホールドアウト、80/20分割）

| モデル | 方向性精度 | 1ステップMAE |
| --- | --- | --- |
| **構造v4（最終モデル、毎日）** | **69.3%** | 0.00166 |
| **構造v4、高信頼25%の日** | **80.0%** | — |
| **構造v4、高信頼13%の日** | **82.6%** | — |
| 構造v3（前バージョン） | 62.0% | 0.00195 |
| LSTM（v2、ディープベースライン） | 59.8% | 0.00187 |
| "変化なし"ベースライン | 50%（コインフリップ） | 0.00186 |

v4をリリースする前に行われた健全性チェック：リッジ回帰は**すべての5つの分割比率0.65–0.85**で勝ちました（毎日の方向性68–71% vs v3の61–65%）、また**毎日のウォークフォワード再適合**でも（69.8%）勝ちました。検証プロトコルは、訓練データのみの特徴スケーリング、訓練データのみのα選択、リークのない信頼しきい値を使用しました。

**誠実に読んでください。** 精度の向上は*方向性の*向上です（毎日69% vs 50%；モデルが最も強い四分位数/八分位数の日だけを呼ぶ場合、約80–86%）。日次FXレベルはノイズに支配されているため、すべてのモデルの1日レベルMAEは「変化なし」のフロアー付近にあります。v4での教訓は、データ生成プロセス（曜日に依存する平均回帰強度を持つ管理されたタカレッグ、プラス10/20日間移動平均への回帰）を理解することが、ディープネットワークをはるかに上回るということです。
