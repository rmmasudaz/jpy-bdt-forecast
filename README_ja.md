# JPY → BDT 為替レート予測

実際の日次JPY→BDT為替レートをダウンロードし、モデル化し、インタラクティブなHTMLダッシュボードで結果を可視化する、セルフコンテインドな機械学習プロジェクトです。

時系列予測の学習演習として、また「データの理解がニューラルネットワークの追加より勝る理由」のレッスンとして構築されました。

## 提供されるもの

| ファイル | 目的 |
| --- | --- |
| `dashboard.html` | **インタラクティブWebダッシュボード** — ダブルクリックで開きます（Chart.js CDNとフォントのためインターネットが必要です）。 |
| `fetch_data.py` | 無料の`fawazahmed0/currency-api`サービスから日次JPY→BDTレート**と2つのUSDレッグ**（USD/JPY、USD/BDT）をダウンロードします。 |
| `train_lstm.py` | 最終的な構造モデルの訓練と評価を行い、LSTMと単純なベースラインと誠実に比較して`model_forecast.json`を作成します。 |
| `build_dashboard.py` | `model_forecast.json`を`dashboard.html`にインライン化します。 |
| `experiment_features.py` | 機能セットのA/Bテスト（USDレッグ、ボラティリティ、モメンタム、曜日の追加）。 |
| `experiment_hybrid.py` | LSTMと構造的平均回帰信号のブレンディングをテストします。 |
| `robustness_check.py` | 「タカレッグの平均回帰」結果を多くの訓練/テスト分割でチェックします。 |
| `data/jpy_bdt_daily.csv` | ダウンロードされた日次系列データ（910日、2024-03-02 → 2026-08-28）。 |
| `model_forecast.json` | ダッシュボードがレンダリングするすべてのモデル出力。 |
| `lstm_model.keras` | 訓練済みのLSTM（ディープラーニングのベースラインとして保存されます）。 |

## パイプラインの実行

```bash
pip install pandas numpy scikit-learn tensorflow-cpu requests
```

## モデリングのストーリー（v1 → v4）

- **対象 = 日次対数リターン、レベルではない。** FXレートはランダムウォークに近い動きをするため、明日の最良の単純予測は今日の値です。リターン（定常性）をモデル化し、累積的にレベルを再構成するのが健全なフレームワークです。
- **v1/v2 (LSTM)。** `[return, |return|]`に基づく2層LSTM、その後2つのUSDクロスレートレッグを追加したものは、~60%の方向性精度で有望に見えましたが、この数値は**安定していませんでした**。同じ設定でもランダムシードによって40–60%のスコアが得られることが判明しました。これは信号ではなくノイズです。
- **v3 (構造分解)。** レートは正確に次のように分解されます：`JPY/BDT = (BDT/USD) ÷ (JPY/USD)`、したがって`r(JPY/BDT) = r(USD/BDT) − r(USD/JPY)`。管理されたUSD/BDTレッグは**平均回帰**します（ラグ1自己相関 ≈ −0.26）；USD/JPYはランダムウォークです。v3はタカレッグの単純なAR(1)平均回帰でした。
- **v4 (曜日条件付きリッジ回帰 — 最終モデル)。** レッグ分析により、タカレッグに2つの追加の予測可能な構造が見つかりました：
  1. **平均回帰は強く曜日依存** — 月曜日のβ ≈ −0.98（週末/日曜日の調整が月曜日にほぼ完全に反転）、一方中週のβは ≈ −0.13のみです。
  2. **レベル回帰** — タカレートは昨日の動きだけでなく、10/20日間移動平均に向かっても戻る傾向があります。

  そのためv4は、`[r_ubラグ1–3、MA10からの偏差、MA20からの偏差、r_uj(t−1)、曜日ダミー、r_ub(t−1) × 曜日相互作用]`に基づく**リッジ回帰**でタカレッグのリターンを予測し、イェンレッグのドリフトを差し引きます。すべての処理は訓練ウィンドウでのみ実行され、訓練データのみで標準化されます。リッジのαは**訓練ウィンドウ内でのウォークフォワード再適合**によって選択されます（テストセットは決して触れられません）。テスト評価は実際の運用を反映しています：モデルは**毎日、これまでのすべてのデータで再適合**されます。
- **振幅校正：** リターン予測は、ホールドアウトされた検証スライスで1ステップレベルMAEを最小化するように選択された`λ`でスケーリングされます。（方向 — 予測可能な部分 — はこの正のスケーリングの影響を受けません。）
- **不確実性：** 95%のバンドは`±1.96 · σ_resid · √h`のように成長します（ランダムウォークのスケーリング）。

## 高信頼（選択的）モード — 約80%への誠実なルート

毎日のFX方向を予測するのは難しいです（ここでは約69%）。しかし、モデルは**信号の弱い日に「予測なし」と言うことができ**、信号が強い場合にのみ予測します。信頼しきい値は**テストセットなしで校正**され（訓練ウィンドウ内のブロックウォークフォワード適合；しきい値 = 予測の|prediction|のパーセンタイル）、凍結されてテスト日に適用されます。ダッシュボードの予測行には、15%カバレッジしきい値を使用した`high_confidence`フラグが含まれています。

## 結果（サンプル外、182日のホールドアウト、80/20分割）

| モデル | 方向性精度 | 1ステップMAE |
| --- | --- | --- |
| **構造v4（最終モデル、毎日）** | **69.3%** | 0.00166 |
| **構造v4、高信頼25%の日** | **80.0%** | — |
| **構造v4、高信頼13%の日** | **82.6%** | — |
| 構造v3（前バージョン） | 62.0% | 0.00195 |
| LSTM（v2、ディープベースライン） | 59.8% | 0.00187 |
| "変化なし"ベースライン | 50%（コインフリップ） | 0.00186 |

v4をリリースする前に行われた健全性チェック：リッジ回帰は**すべての5つの分割比率0.65–0.85**で勝ちました（毎日の方向性68–71% vs v3の61–65%）、また**毎日のウォークフォワード再適合**でも（69.8%）勝ちました。検証プロトコルは、訓練データのみの特徴スケーリング、訓練データのみのα選択、リークのない信頼しきい値を使用しました。

**誠実に読んでください。** 精度の向上は*方向性の*向上です（毎日69% vs 50%；モデルが最も強い四分位数/八分位数の日だけを呼ぶ場合、約80–86%）。日次FXレベルはノイズに支配されているため、すべてのモデルの1日レベルMAEは「変化なし」のフロアー付近にあります。v4での教訓は、データ生成プロセス（曜日に依存する平均回帰強度を持つ管理されたタカレッグ、プラス10/20日間移動平均への回帰）を理解することが、ディープネットワークをはるかに上回るということです。
