# JPY → BDT 為替レート予測

実際の日次JPY→BDT為替レートをダウンロードし、モデル化し、インタラクティブなHTMLダッシュボードで結果を可視化する、セルフコンテインドな機械学習プロジェクトです。

![JPY→BDT 予測ダッシュボード](assets/shot_full.png)

時系列予測の学習演習として、また「データの理解がニューラルネットワークの追加より勝る理由」のレッスンとして構築されました。

## パイプラインの実行

```bash

# または個別にパッケージをインストール

# プロジェクトルートからパイプラインを実行

```

## モデルアーキテクチャと進化

このプロジェクトは、JPY→BDT為替レートの予測のために**複数のモデリングアプローチ**を探索し、複雑なニューラルネットワークを使用するだけでなく、基盤となる通貨市場のメカニズムの理解に重点を置いています。

### **重要な洞察：通貨ペアの分解**
プロジェクトは通貨市場に関する重要な観察から始まります：
```
JPY/BDT = (BDT per USD) / (JPY per USD)
r(JPY/BDT) = r(USD/BDT) − r(USD/JPY)
```

**これが重要な理由：**
- **USD/JPY（円レッグ）：** 自由変動の市場レート（ランダムウォークの動作）
- **USD/BDT（タカレッグ）：** バングラデシュ銀行による管理レート（強い平均回帰を示す）

### **モデルのバージョン**

#### **v1: 単純LSTM（ベースライン）**
- **アーキテクチャ：** 2層LSTM（64/32ユニット）+ ドロップアウト（0.2）
- **特徴：** 日次対数リターン
- **パフォーマンス：** 約60%の方向性精度（不安定 - ランダムシードによって40-60%の範囲で変動）
- **限界：** 通貨市場の構造を理解していない

#### **v2: 強化LSTM**
- **改善：** USDクロスレートレッグを特徴として追加
- **特徴：** [return, |return|, USD/BDT, USD/JPY]
- **パフォーマンス：** 約60%の方向性精度（依然として不安定）
- **限界：** 構造的洞察のない複雑なモデル

#### **v3: 構造的AR(1)モデル**
- **画期的進歩：** 通貨分解に焦点
- **アプローチ：** USD/BDTの平均回帰を予測、USD/JPYはランダムウォークとして扱う
- **特徴：** USD/BDTのラグ付きリターン
- **パフォーマンス：** 62.0%の方向性精度（分割間で安定）
- **重要な発見：** USD/BDTはラグ1自己相関が-0.26（強い平均回帰）

#### **v4: 曜日条件付きリッジ回帰（最終モデル）**
- **アーキテクチャ：** 曜日依存の特徴を持つリッジ回帰
- **特徴：**
  - USD/BDTのラグ付きリターン（1-3日）
  - 10/20日移動平均からの偏差（レベル回帰）
  - USD/JPYのラグ付きリターン（ランダムウォークのベースライン）
  - 曜日ダミー（月曜日から金曜日の指標）
  - 相互作用項：USD/BDTラグ × 曜日（曜日効果を捉える）
- **主要なイノベーション：**
  - 月曜日効果：β ≈ -0.98（週末の調整がほぼ完全に反転）
  - 中週効果：β ≈ -0.13（弱い平均回帰）
- **パフォーマンス：** **57.5%の方向性精度**（リークのない毎日のテスト精度）
- **高信頼モード：** 最も強い25%の信号のみを呼び出すと61.8%の精度（34/182日）

### **モデル評価プロトコル**
- **80/20時系列分割：** 728日間の訓練、182日間のテスト
- **ウォークフォワードバリデーション：** モデルは毎日利用可能なデータで再調整
- **訓練のみの校正：** すべてのハイパーパラメータはテストデータに触れずに選択
- **データリークなし：** 訓練、検証、テストセットの厳格な分離（$t-1$ラグの徹底）

## 高信頼（選択的）モード — 強いシグナル時のみのトレード

毎日のFX方向予測はノイズが多く困難です（v4で57.5%、v3で62.0%）。しかし、モデルは**信号の弱い日に「予測なし」と言うことができ**、信号が強い場合にのみ予測します。信頼しきい値は**テストセットなしで校正**され（訓練ウィンドウ内のブロックウォークフォワード適合；しきい値 = 予測の|prediction|のパーセンタイル）、凍結されてテスト日に適用されます。選択的モードでは、公称25%カバレッジ（34日）で**61.8%**、公称15%カバレッジ（19日）で**57.9%**の精度に達します。ダッシュボードの予測行には、15%カバレッジしきい値を使用した`high_confidence`フラグが含まれています。

## 結果（サンプル外、182日のホールドアウト、80/20分割）

| モデル | 方向性精度 | 1ステップMAE |
| --- | --- | --- |
| **構造v3（1パラメータ月曜反転ベースライン）** | **62.0%** | 0.00195 |
| **LSTM（v2、ディープベースライン）** | 59.8% | 0.00187 |
| **構造v4（最終モデル、毎日）** | 57.5% | 0.00185 |
| **構造v4、高信頼25%の日** | **61.8%**（34/182日） | — |
| **構造v4、高信頼15%の日** | 57.9%（19/182日） | — |
| "変化なし"ベースライン | 50%（コインフリップ） | 0.00186 |

分割比率（70%、75%、80%）にわたるロバスト性チェック：
移動平均レベル特徴量における先読みリークを完全に排除（$t-1$ラグ）した結果、1パラメータのv3月曜反転ベースラインがすべての分割で**62.0%〜64.7%**の方向性精度を達成し、17特徴量のv4モデル（**57.5%〜58.4%**）を上回りました。これは、ノイズの多い管理通貨体制において、特徴量の過剰な追加はノイズに過学習しやすい一方、真の制度的メカニズム（週末調整の月曜反転）を捉えた簡潔な構造モデルの方が長期的に堅牢であるという重要なMLの知見を示しています。

**誠実に読んでください。** 精度の向上は*方向性の*向上です（v4で57.5%、v3で62.0% vs 50%コインフリップ；選択的高信頼モードでは61.8%）。日次FXレベルはノイズに支配されているため、すべてのモデルの1日レベルMAEは「変化なし」のフロアー付近にあります（0.00185 vs 0.00186）。教訓は、データ生成プロセス（曜日に依存する平均回帰強度を持つ管理されたタカレッグ）を理解し、先読みリークのない堅牢な構造シグナルを抽出することの重要性です。
